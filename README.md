
# 📸 3.js Portfolio Project

A modern, animated personal portfolio built with **Three.js**, Vite, and vanilla JavaScript—based on JavaScript Mastery’s tutorial and fully customizable to reflect your style and work.

## 🌟 Features

- Engaging **3D animated background** using Three.js
- Fast development using **Vite**
- Clean code with **ESLint**
- Mobile-responsive design
- Simple structure, easy to extend

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or Yarn

### Installation

```bash
git clone https://github.com/pushparajwastaken/3js_and_portfolioProject.git
